About The Platform

Bridging the Information Gap for Campus Activities

In traditional university ecosystems, student event notifications are dispersed across uncoordinated notice boards, departmental noticeboards, and scattered group chats. Students miss out on skill-building workshops, networking seminars, and creative competitions.

EventEase unifies campus life. Built specifically as a clean, responsive academic web application for 25CS208 Web Technology, it empowers college students to discover, register, and manage their campus life from one centralized portal.

✓
Centralized Event Aggregator: All college departments, technical societies, and cultural clubs publish to one unified calendar.
✓
Instant Digital Verification: Automatically generates digital tickets with student IDs and simulated QR passes.
✓
Zero Framework Bloat: Built strictly with semantic HTML5, modern CSS Grid/Flexbox, and pure Vanilla JavaScript ES6+.
🏛️

25CS208 Web Technology Microproject

Developed under academic curriculum guidelines to demonstrate mastery of responsive UI/UX architecture, client-side state persistence with LocalStorage, cryptographic password hashing via Web Crypto API, regular expression validation, and accessible web standards.

HTML5 CSS Grid ES6+ Vanilla JS LocalStorage Fetch API
